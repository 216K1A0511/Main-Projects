# 3. Student Portal Working Process

## Overview
The **Student Portal** is a read/interact view, allowing the student to view their academic trajectory, access resources, interact with placements, and manage extracurricular activities.

## Working Process & Files involved

1. **`student-dashboard.html`**
   - **Role:** Quick personal overview.
   - **Process:** Shows current GPA, attendance percentage, upcoming assignments, exam countdowns, active tasks, and library due dates. Contains quick-modals for Profile settings and Internal Email.

2. **`student-academic-setup.html`**
   - **Role:** Academic workflow.
   - **Process:** The student navigates this space to view curriculums, download lesson plans/notes uploaded by faculty, submit assignments mathematically or via text, and view their time table.

3. **`student-extracurricular.html`**
   - **Role:** Personal development.
   - **Process:** Used to browse available clubs/societies, register for events/hackathons, and view event galleries.

4. **`student-placements.html`**
   - **Role:** Careers logic.
   - **Process:** Opt-in for campus recruitment drives, upload resumes, see upcoming placement training, and check selection statuses.

5. **`student-requests.html`**
   - **Role:** Administrative interactions.
   - **Process:** Dedicated interface to apply for Leaves (vacation/sick), request Hostel Gate Passes (syncs to Warden), request physical documents (Bonafide, Transcripts), and raise grievances/complaints (syncs to Admin HR).
